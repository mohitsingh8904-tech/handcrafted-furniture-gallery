# Handcrafted Furniture Workshop Gallery

A premium, responsive furniture management dashboard designed to showcase and manage handcrafted furniture collections.

## Project Overview

The Handcrafted Furniture Workshop Gallery is a web-based dashboard that allows users to manage furniture inventory through a clean and professional interface.

## Features

- Premium corporate dashboard UI
- Add new furniture pieces
- Edit existing furniture details
- Delete furniture records
- Search furniture by name and material
- Filter furniture by category
- Dynamic inventory statistics
- LocalStorage data persistence
- Form validation with error messages
- Empty state handling
- Loading indicator
- XSS-safe text rendering using `textContent`
- Responsive mobile, tablet and desktop layout
- Analytics interaction logging

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/mohitsingh8904-tech/handcrafted-furniture-gallery.git
```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension.

4. Right-click `index.html` and select **Open with Live Server**.

## Data Storage

Furniture records are stored in the browser's LocalStorage. Data is local to the browser and is not synchronized with a server.
